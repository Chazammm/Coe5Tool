    At the workbench

    Target & format
    Vanilla creates native weapon fragments. CoE5SE adds linked spells and the experimental field (5.43 / 2.13.0). File format is detected on opening. Source format… offers an advanced interpretation override. Target changes never convert source or remove dependencies.
    Source & reference
    The editor reads your source. The library is a separate reference, with its version and evidence shown. Browsing it changes no source text.
    Apply & export
    Apply changes puts field edits into the draft. Review shows that draft. Export copy writes a new file; the original cannot be overwritten.
    Unavailable fields
    Only supported, unambiguous values can be changed here. Read-only fields explain their limits. Source checks cover selected syntax and bounds, not the whole game.
    Effects & controls
    VFX and sound values are metadata, with no effect preview. Tab moves between controls. Escape closes help or the library when focus is inside it.

          Damage types & test limits ↗

          The weapon name follows the spell name until you edit it. Names may differ. This form creates a new weapon; a spell can also be assigned a differently named or existing weapon later using the source editor and library.

          Names, damage & source limits

          Safe creation subset: printable ASCII, no quotes, # or backslash; spell names up to 47 bytes, weapons up to 63. Names are preserved as entered.

          Weapon base damage and spell attack payload are separate. Damage-type help describes their interpretation. Mask builders use exact decimal integers; no flags are added automatically.

          0 selects one target. Positive values count nearby targets/squares. Standalone tests accept codes 0–5. The game chooses placement and the actual victims.

          Optional weapon effects & sound

          Blank fields are omitted, with no assumed values. Supply Flight mode (1–9) and Flight look together. Mode 1 uses sprite IDs; other modes use effect IDs. Numeric checks do not establish catalog membership. No effect or audio preview.
