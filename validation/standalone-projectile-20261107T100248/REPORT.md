1. In **Vanilla CoE5**, choose **New weapon**, enter a unique name, and choose **Use projectile settings**. This fills range 5, sprite flight mode 1, Ballista bolt #7 and Flame impact #68. It leaves the entered weapon name, damage, damage type and initiative alone. Creator screenshot (local evidence)
2. Create the draft and open **Test ranged weapon with CoE5SE…**. Review the fixed private carrier and its single target. The carrier attack payload was **8** in this test. ## Scope and implementation evidence

The native manual assigns separate meanings to the attack-row payload, weapon range, flight mode, sprite and strike effect. Sprite mode 1 uses the Fly Sprites table. `look` selects a target impact. The supplied WeaponTester has a ranged scratch-weapon carrier and stand-in experimentation. This fixture instead equips one new, uniquely named weapon on one new carrier. It copies Spearman stats, clears the inherited attacks and declares a single regular ranged attack. No saved campaign, spell, forced attack, range override or vanilla record write participates. [Native modding manual](https://www.illwinter.com/coe5/coe5modding.html) · [WeaponTester inspection](../../docs/weapon-tester-and-mode-research-20261106/01-weapon-tester.md)

The pinned extender exposes the row type, resolved weapon and attack value, plus weapon fields and the main-menu battle APIs. The helper checks the private slot boundaries, unique names, type, weapon ID, payload, absence of a second row, base weapon settings and visual IDs twice, before opening and before starting the battle. For a specified impact it also requires a runtime effect name. Native deployment supplies the starting geometry. The Windows host independently reconstructs the allowed fixture from the native source before accepting the package. [Pinned API](https://github.com/musical-pianist/coe5se/blob/9e22d27c32ee15392fc370027d00dbc750b5d19b/coe5.lua) · [Native field implementation](https://github.com/musical-pianist/coe5se/blob/9e22d27c32ee15392fc370027d00dbc750b5d19b/src/lua_test_battle.h) · [Mod slot definitions](https://github.com/musical-pianist/coe5se/blob/9e22d27c32ee15392fc370027d00dbc750b5d19b/src/table_move.h)

The ranged test accepts one intact generated native weapon, slash/blunt/pierce, base damage 0–99, initiative 1–99, attack payload 1–99, area 0, range 2–9 and sprite mode 1. The supported sprite IDs are Arrow 0, Javelin 1, Sling stone 2 and Ballista bolt 7. Impact can be omitted, Blood Burst 34 or Flame 68. These are fixture bounds. Only the ballista-bolt/flame combination above was observed in game. Other sprite combinations, particles, sound commands, special or multiple attack rows, area effects and nonphysical payloads need their own validation. Unsupported configurations remain available for source editing and separate export within the editor's existing capabilities.
