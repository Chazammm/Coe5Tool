## Defects and corrections

1. Prepared/result lists did not refresh an exited resumed child, and starting another saved preparation could lose its exit receipt. Refresh now persists the currently owned child before either list and before a new saved binding. A native regression covers a live child, both list routes, rebinding, exit code and used-session refusal. The already lost original Fireball exit code remains unknown.
2. Browser validation of official comparison returns still accepted only 3.2.2. It now uses the explicit 3.2.2/3.3.0 capability predicate, with future/old-incompatible versions refused. Captions use the bound runtime and an unavailable result clears earlier summary text. The in-game comparison title is version-neutral; only its exact historical cosmetic variant is also accepted for retained preparation/review. No combat/callback helper behavior changed.

327 script checks and 116 native checks passed after correction. Actual rebuilt desktop review selected the new 3.3.0 mixed session, showed 4/4 defenders, two attempts and unknown hit attribution. Explicit Apply/export produced a separate full-source copy with exactly look 68→34, flymode 1→2 and flylook 7→65; the original example remained byte-identical. Selected-spell desktop return/export is recorded in the final verification supplement.
