## Observe an original

Open **Explore Vanilla spells & weapons** on the welcome screen, or **Vanilla library** in the header. It reads the configured executable; otherwise choose **Load installed 5.43 spells & weapons…**. Search part of a name or `#ID`. IDs/category distinguish duplicate names. Facts are partial metadata, not a complete definition or preview. Related-record navigation follows same-catalog IDs.

Choose **Observe original with CoE5SE…**, select a target/count and **Prepare game test**. Starting is separate. Use the displayed **WB test: …** menu entry in the isolated game and choose an offered native caster/carrier. **Battle (AI)** may never use the selected record; check a named cast/attack and visuals separately. Close the field and Quit normally.

Back in Workbench, refresh and open **Previous observations…** or **Prepared tests…**. Select the exact new session. Recorded facts do not confirm hits or visuals. Personal observations, video and combat logs remain separate. Originals have no Apply/export-to-draft action; a faithful editable clone is unsupported.

## Edit your mod

Open or drop **one** `.c5m` / `.c5se`. Multiple/unsupported drops are refused without partial import. Format is detected; an advanced interpretation override does not convert it. Search the spell/weapon overview; source lines distinguish duplicates. Follow a known spell→weapon link to edit its visuals.

Edit supported fields and **Apply changes** to the draft. Original files and unrelated text stay intact. Eligible selections offer a CoE5SE test action; its dialog says exactly which definitions/dependencies it will load or refuse. No arbitrary mod section is silently loaded. Unsupported content remains editable/exportable with an explained test limit.

Custom spell tests use a **forced item-style cast**, sometimes extending range. Private standalone-weapon tests use a carrier's native **AI battle**. Neither validates the entire mod, ordinary campaign AI, all ranges/statuses or saves.

After an editable experiment, **Saved test values** shows the bound session and settings. Select values explicitly; newer edits require a conflict choice before replacement. Missing optional fields can be added only in safely identified source. Other pending edits remain. **Export copy** writes the whole draft separately, preserving comments, formatting and unrelated content.

## Create a draft

Use **New spell & weapon** for a CoE5SE pair. Set **Target → Vanilla** for **New native weapon**. Search choices rather than memorizing IDs; special damage/payload cases explain their inputs and test limits. Visual choices never silently choose damage type.

**Try a supported example** opens a linked pair in CoE5SE mode or a simple native melee weapon in Vanilla mode. It is a fragment, not an installable whole mod or proof that this exact draft was tested in game. Edit/apply, test a supported selection, then export for integration.

## Prepare, run and resume

**Prepare game test** builds canonical files and asks the native host to validate/copy a fresh private setup. It launches no game. If requested, choose your game executable and official extracted extender through the file dialogs. Fingerprint, ownership, source, mod-file and active-game checks stay mandatory. No downgrade, patch or runtime download occurs.

**Advanced: test files & ZIP export** retains file preview/export. **Advanced: use reviewed test files** retains separate native preparation. A private profile may need the separately explained first-time setup. Never substitute a campaign.

Keep Workbench open during the game. Close the field, **Quit** normally, then refresh the app. Describe flight and impact separately; an exit is not an effect verdict, battle count is not AI cast count, and a visual burst is not proof of hits on every square.

Each preparation retains its runtime version and paths. Older records without a version remain 2.13.0; selecting a new runtime never upgrades them. After reopening, **Prepared tests… → select → Check before resuming → Start saved test** works only for safe unused snapshots. Used/stale/incomplete/incompatible snapshots explain the refusal. Review their evidence or prepare afresh; do not bypass checks. No personal preparations are supplied in the ZIP.

Legacy **roster-v1** supports mixed native groups in **2.13.0 only** when a separately available, authorized private component is present. It is not included in this download. Retained staged sessions keep their independent checks. Official 3.2.2 now has a separate fixed mixed-group preview: 2–8 native types, total 200, one AI battle per launch, read-only results and no rollback claim. Fresh gameplay acceptance is pending. See [official mixed fields](OFFICIAL-MIXED-0182.md). Existing single-type comparison/return stays separate. No arbitrary mod-added units or wave system is promised.

Remaining limits include Windows x64, one pinned game build, partial metadata, distinct historical provenance, no desktop VFX/audio renderer, no lossless built-in clone and no Vanilla-only integrated field. A selectable ID/source shape does not establish universal gameplay compatibility.
