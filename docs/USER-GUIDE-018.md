# Using CoE5 Workbench 0.18.0

## Start

Extract the whole Windows ZIP into a writable folder and open CoE5Workbench.exe. .NET is included. If WebView2 is missing, Workbench explains how to get Microsoft's Evergreen Runtime. You do not need the game for supported source editing and export.

Choose one of the three starting actions. The Target menu controls creation and available testing features; it never converts an open file. File format is detected on opening. Source format is an advanced reading override.

## Explore a Vanilla spell or weapon

1. Choose Explore Vanilla spells & weapons. Load the installed catalog from your supported CoE5 5.43 executable if requested.
2. Search part of a name or an ID. The selected record shows the known values, links and data source. This is partial metadata, not a complete definition or visual preview.
3. Choose Observe original with CoE5SE for an eligible record. Select a target and count, then Prepare game test. If requested, select your own compatible game and official extracted extender files.
4. Start explicitly when ready. Open the displayed WB test entry at the isolated game's main menu. Choose an offered native caster or carrier, then Battle (AI).
5. Check whether the log names the selected spell or weapon. Observe flight and impact separately. AI may never use the selection; a returned battle alone is inconclusive.
6. Close the field, return to the main menu and Quit normally. Back in Workbench, use Previous observations or Prepared tests to review the saved facts.

Built-in originals stay read-only. Workbench does not turn their partial metadata into an editable clone. Historical reference entries do not prove availability in your installed game.

## Edit a mod

1. Open or drag in one .c5m or .c5se file. UTF-8 source is supported; unsupported and multi-file drops are refused. Export your current work before replacing it, or decline the replacement prompt.
2. Search the source index or open Source overview. Spell and weapon lists retain their search position when you return from detail. Source lines distinguish duplicate names.
3. Edit supported fields. Search choices by partial name or ID. A spell's resolved weapon link lets you reach its weapon effects. Unknown or ambiguous values explain their limits.
4. Apply changes to the draft. To try an eligible selection, choose Test selected. The setup explains which definitions are loaded and any missing dependencies. It does not load or validate the complete mod.
5. After testing, open Test results or Review saved values. Select the values to keep. Newer conflicting edits need an explicit replacement choice; unrelated pending edits remain.
6. Review changes, then Export copy. A new complete source file preserves unrelated text, comments and formatting. The opened original cannot be overwritten through this action.

Custom spell tests use a forced item-style cast and may extend range. Standalone weapon tests use a private carrier's AI battle. Neither establishes general combat, AI, timing or save compatibility. Visual settings and damage behavior remain separate.

## Create

New spell & weapon creates a CoE5SE pair. Select Target → Vanilla for New native weapon. Try example provides a supported starting fragment. Set damage and any effects, create the draft, then edit, test an eligible selection or export it for integration into your mod. A fragment is not a complete installable mod.

## Prepare, compare and return

Preparing does not launch the game. All integrated tests require supported CoE5 5.43 and official CoE5SE 3.3.0, 3.2.2 or 2.13.0 files. Newer versions are not accepted automatically. File identity, ownership, source and active-game checks remain mandatory.

Supported ranged comparison can use fresh same-type or official 3.2.2/3.3.0 mixed native targets. Apply a supported visual configuration, run one AI battle, go Back and compare another configuration. Save/select values explicitly and Finish when done. Target identities belong to each individual battle. No mixed waves or arbitrary mod-added targets are promised. Legacy 2.13.0 mixed tests require a separately available authorized component; it is not in this package.

Recorded settings, returned cast/battle calls and your own visual observations are different evidence. HP differences do not identify an attacker or confirm a hit. Attack-time positions are unknown; official field closure is not proof of complete record rollback.

## Resume and close

Prepared tests lists earlier preparations and results. Select a test, Check before resuming, then Start saved test only if ready. Used, stale, incomplete or incompatible tests explain why they cannot start; prepare a new test instead. Resuming uses the saved source snapshot and leaves your open draft untouched.

Export your draft before closing; it is not automatically restored next time. Unsaved work prompts before replacement or exit. Prepared tests and saved results remain on the same Windows account. After reopening, open your exported source to continue editing.

For a game that does not respond to menu Quit, use its normal title-bar Close on the isolated window. Do not terminate another game. The earlier Quit incident remains unexplained; a fresh comparison did quit normally after visiting Credits.
