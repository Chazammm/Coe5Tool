# Workbench 0.18.0

A clearer Windows release for finding, editing and trying supported CoE5 spells and weapons.

- Three starting routes: explore built-ins, open a mod or create a definition. The empty source index and irrelevant draft actions stay out of the way until a source is open.
- Shorter test instructions, Test results as a consistent action, and optional compatibility/session details. Recorded settings, cast calls and visual observations remain separate.
- Portable Windows x64 download with .NET 10.0.15 included. No .NET install, terminal or SDK required. WebView2 remains an explicit prerequisite with a helpful missing-component screen. Readable native help and an offline START-HERE.html are included.
- Fixed the source launcher pointing at an older build. Kept rc.3 prepared/result contracts alongside previous supported sessions.
- Existing private melee/ranged tests, supported sprite/particle comparison, official mixed groups, selected mod spell/weapon testing, original Vanilla observation and protected value return/export remain available within their documented bounds.

Editing/native export work offline. Integrated tests require the user's own supported CoE5 5.43 and official CoE5SE 3.3.0, 3.2.2 or 2.13.0.
